Introduction

Thank you for purchasing the LogicBit News Platform — a complete news website system built with Next.js 14 (websites + admin panel), NestJS 10 (API) and PostgreSQL. One installation runs as many news sites as you like, each with its own domain, design, content, ads and users, all managed from one admin panel.

  • 60 ready templates (6 layout families × 10 colour palettes, including dark mode) and 5 article layouts — every colour, font, size and layout part can be changed in the admin with a live preview.
  • Automatic homepage built from your own categories, or a drag-and-drop homepage builder with 13 block layouts.
  • Ads manager — 36 ad places, unlimited ads, one ad in many places, device / page / category targeting, scheduling, rotation, click counts, popup and sticky ads, and an "ad spots" mode that shows every place on your live site.
  • Built for Nepali news — Bikram Sambat dates, Nepali digits, "५१ मिनेट अगाडि" relative time, 16 self-hosted Devanagari/Latin fonts. English sites work just as well.
  • WordPress importer — move a site that uses the LogicBit News WordPress theme (posts, categories, tags, reporters, settings and ads) in one go.
  • SEO ready (Open Graph, JSON-LD NewsArticle, sitemap.xml, RSS feed, robots.txt), fast server rendering and fully responsive.

Installation (one command)

  1. Point your domain to the server. At your domain registrar or DNS (e.g. Cloudflare) add an A record for yoursite.com and www.yoursite.com → your server's IP. Wait until ping yoursite.com shows that IP (usually minutes, sometimes a few hours).
  2. Upload the code. Copy LogicBit-News-Platform.zip to the server (e.g. with an SFTP app such as FileZilla / WinSCP, or scp): 
    scp LogicBit-News-Platform.zip root@YOUR_SERVER_IP:/root/
  3. Connect by SSH and unzip: 
    ssh root@YOUR_SERVER_IP
sudo apt-get update && sudo apt-get install -y unzip
sudo mkdir -p /var/www && cd /var/www
sudo unzip /root/LogicBit-News-Platform.zip
cd logicbit-news-platform
  4. Run the installer (5–10 minutes): 
    sudo bash install.sh yoursite.com you@email.com
    It installs the software, creates an empty database with a random password, writes apps/api/.env, builds and starts both apps with PM2 (they start again after a reboot), configures Nginx and adds HTTPS. The database password is saved in /root/logicbit-news-credentials.txt.
  5. Open https://yoursite.com/install in your browser and finish with the web installer (next section).

Installer options

Web installer

  1. Open https://yoursite.com/install.
  2. Enter the site name, domain, language (Nepali or English), pick a template, choose whether to add demo content (sample news, categories, reporters and ads — recommended for a first look; you can delete it later) and create the admin account (email + strong password).
  3. Click Install. You are logged in to the admin panel at https://yoursite.com/admin.
Finish /install right after the server installer — until then anyone who opens that page could install the site. After the first install the page is locked.

After installing — checklist

  1. Site Settings → General: logo, favicon, "No image" photo, tagline, language.
  2. Design & Templates: choose your template, then adjust colours, fonts and font sizes.
  3. Categories (with colours), Menus (Main menu, Top bar, Footer) and Team / Byline (reporters with photos).
  4. Homepage Builder: keep Automatic (recommended) or switch to Custom.
  5. Ads Manager: add your ads — open yoursite.com/?lb_ad_spots=1 to see every ad place.
  6. Site Settings → Footer: team, contact details, registration number, copyright.
  7. Users: create Editor / Author accounts for your team — never share the admin password.
  8. Set up the daily backup and the firewall.

Writing news

  1. Posts → Add New Post. Write the title and the story in the editor (headings, lists, links, images, YouTube).
  2. Pick categories (and a primary category for the badge), add tags and a featured image with caption.
  3. Post options:
    • 📝 Post Subtitle — shown under the title.
    • 🔥 Show on Homepage (Flash) — the big "main news" at the top of the homepage. Only ticked news appear there.
    • ⚡ Breaking News — shows in the breaking ticker.
    • ⭐ Featured Post, 🎬 YouTube Video (URL or ID — embedded automatically), 📅 Custom Published Date.
    • 👤 Select From Team (Byline) or ✍️ Other Byline — who wrote it.
    • SEO title / description — optional; the title and summary are used otherwise.
  4. Publish now or set a date and time to schedule.

No photo? The site uses the first photo inside the story, then your "No image" photo, then your logo — never an empty box.

Homepage

  • Automatic (recommended) — the homepage is built from your categories in the order that suits the template. Changing the template changes the homepage too.
  • Custom — add, remove and drag sections; for each choose the category, layout (13 options), number of posts, colours, sidebar and an ad slot.
  • Big main news — shows only news ticked "Show on Homepage (Flash)". When nothing is ticked you can hide the area or show the latest news instead.

Ads manager

  1. Ads Manager → Add ad. Choose an image (with an optional separate phone image) and a link, or paste ad code (AdSense, HTML, JavaScript).
  2. Tick the places where it should appear — one ad can be in many places (e.g. "Every sidebar").
  3. Optional targeting: device (desktop / phone), page type (home, news, category, page, search) and categories.
  4. Optional start / end dates — the ad hides itself after the end date. Status shows Live, Ends soon, Scheduled, Expired or Off.
  5. For in-article ads choose the paragraph number and "repeat every N paragraphs".

36 places: header (top, beside logo, below menu), homepage (top, beside main story, below main news, between sections 1–10, sidebar, bottom), news page (top, below title, below image, in-content, bottom, sidebar, after related), category pages, pages, footer, popup and sticky bottom bar.

See ad spots on my site: open yoursite.com/?lb_ad_spots=1 (logged in) to see every place as a dashed box with "+ Add ad here" / "✎ Edit ad". ?lb_ad_spots=0 turns it off. Rotate (Ad places tab) shows one random ad per page view in that place.

Nepali language & dates

  • Choose Nepali as the site language (installer or Site Settings → General). Interface text, dates and digits switch to Nepali.
  • News dates use Bikram Sambat (e.g. २०८३ कार्तिक ९, सोमबार) and relative time ("५१ मिनेट अगाडि" or "अघि" — Site Settings → Misc).
  • Top bar date: Automatic, Nepali, English or both (Site Settings → Top bar).
  • Fonts are self-hosted (no Google Fonts requests): Mukta, Noto Sans/Serif Devanagari, Yantramanav, Martel, Khand, Baloo 2, Hind, Tiro Devanagari Hindi, Laila and Latin pairs.

More sites (multi-site)

  1. Point the new domain's DNS A record to the same server.
  2. On the server: 
    cd /var/www/logicbit-news-platform
sudo bash add-domain.sh newsite.com you@email.com
  3. In the admin: All Sites → New site and enter the domain newsite.com (or add it under an existing site's Domains).

Each site has its own design, content, ads, menus and settings. One login reaches all the sites you have access to.

Move from WordPress

For sites using the LogicBit News WordPress theme (older and current versions):

  1. Upload wordpress-plugin/logicbit-headless-export.php to the WordPress site's wp-content/plugins/ folder and activate LogicBit Headless Export.
  2. In WordPress: Users → Profile → Application Passwords → create one.
  3. In this admin: Import / Export → Import from WordPress → WordPress URL, username and the application password → Start.

Posts with all post options, categories with colours, tags with images, reporters, Customizer settings and ads are imported. Running it again updates instead of duplicating. Photos stay on the WordPress server (same URLs) — move the uploads folder before switching WordPress off. For very large sites use the command line:

cd /var/www/logicbit-news-platform/apps/api
npm run import:wp -- --site=SITE_SLUG --url=https://oldsite.com --user=admin --pass="xxxx xxxx xxxx xxxx" --max=20000

Updating

  1. Download the new version from LBS Market → My Account → Downloads and upload LogicBit-News-Platform.zip to /root/.
  2. Run: 
    cd /var/www
sudo bash logicbit-news-platform/backup.sh          # backup first
sudo unzip -o /root/LogicBit-News-Platform.zip       # replaces code only — .env and uploads stay
cd logicbit-news-platform && sudo npm run update   # build + restart

Database changes are applied automatically when the API starts. Your content, settings and photos are kept.

Backup & restore

sudo bash /var/www/logicbit-news-platform/backup.sh
# → /var/backups/logicbit-news/lbnews-YYYY-MM-DD-HHMM.tar.gz (the last 14 are kept)

Daily at 2:30 AM — sudo crontab -e and add:

30 2 * * * bash /var/www/logicbit-news-platform/backup.sh >/dev/null 2>&1

A backup contains the database, uploaded photos and the .env file. Copy backups to another place too (another server, Google Drive, S3…).

Restore on a new server

Run install.sh on the new server (do not open /install), then:

cd /var/www/logicbit-news-platform
mkdir /tmp/r && tar -xzf lbnews-2026-11-02-0230.tar.gz -C /tmp/r
pm2 stop all
DB=$(grep DATABASE_URL apps/api/.env | cut -d'"' -f2)
pg_restore --clean --if-exists --no-owner -d "$DB" /tmp/r/database.dump
tar -xf /tmp/r/uploads.tar -C apps/api
pm2 start all

Security checklist

  • Finish /install immediately after running the installer.
  • Firewall — allow only SSH and web: 
    sudo ufw allow OpenSSH && sudo ufw allow 'Nginx Full' && sudo ufw enable
    Ports 3000 and 4000 must not be open to the internet (Nginx forwards to them).
  • Use strong passwords and give your team Editor / Author accounts, not admin.
  • Keep the server updated: sudo apt-get update && sudo apt-get upgrade.
  • Daily backups, stored off the server.

Troubleshooting

ProblemWhat to do
Site does not open / 502 Bad Gatewaypm2 status → pm2 logs lb-web / pm2 logs lb-api → pm2 restart all
HTTPS was not addedCheck DNS: dig +short yoursite.com must show the server IP. Then run sudo bash install.sh yoursite.com you@email.com again.
Photo upload failsThe upload limit is 10 MB per photo — resize large camera photos (2000 px wide is plenty).

Forgot the admin passwordAnother super admin can set a new one in Users → Edit. Otherwise contact support.
Wrong site shows for a domainAdd the domain under All Sites → (site) → Domains exactly as typed in the browser (with and without www).

For developers

  • Local development: npm run dev:api and npm run dev:web in two terminals, then http://localhost:3000/install. Needs Node.js 20 and PostgreSQL.
  • Type-check everything: npm run typecheck (TypeScript strict mode).
  • Templates: apps/web/src/lib/templates/presets.ts — add a palette with one line in PALETTES, a family in FAMILIES.
  • Database: Drizzle ORM; schema in apps/api/src/db/schema.ts, SQL migrations in apps/api/drizzle/.
  • Docker (optional): cp .env.example .env, set DB_PASSWORD and JWT_SECRET, then docker compose up -d --build.
  • More technical notes (field mapping, API reference): README.md.

FAQ

Can I use shared hosting / cPanel? No — a VPS with root access is needed (Node.js + PostgreSQL). Small VPS plans cost about US$6–12 per month.

How many sites can one installation run? As many as the server can handle. Each needs its own domain.

Do I need WordPress? No. WordPress is only needed if you want to import from an existing WordPress site.

Is it in English or Nepali? Both. Each site can be English or Nepali.

Can I install it for a client? See the licence terms in licensing/LICENSE.txt.
