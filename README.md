# Business-Listing

Monorepo for the Universal Business Listing Theme project.

- `backend/` - NestJS + Prisma + PostgreSQL API (see backend/README.md)
- `frontend/` - Next.js frontend (see frontend/README.md)
- `docs/` - Project documentation, including the database ERD (see docs/erd.md)

## Setup

Each folder has its own README with setup instructions. Backend and frontend run as separate projects - see each folder's package.json for dev scripts.
